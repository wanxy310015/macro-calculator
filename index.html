按身体信号微调（视频核心逻辑）
🍽️ 很饿、想吃米饭馒头粗粮 → 说明碳水利用率高，碳水 +0.5 g/kg（如 3 → 4），此时蛋白可略降。
😌 微微饥饿、训练有欲望、精神好 → 最佳状态，不动，保持住。
😕 完全不饿、对食物没渴望、胀气放屁多且臭 → 吃多了，碳水 −0.5~1 g/kg（回到 3 附近），蛋白略升；稳定 10 天~半个月再评估。
〰️ 整体节奏是波形：拉高 → 稳定一阵 → 降回 3.5 或 3 → 再拉高，像波浪一样慢慢上行，避免忽高忽低。
计算依据（来自视频原话）
  • 脂肪：「每公斤体重 0.6 到 0.8 克，脂肪就够用了」（06:19），注意 Omega-6/3 平衡（多补 Omega-3：亚麻籽油、鱼油）。
  • 蛋白质：「经常锻炼的话，基本上 1.2 到 2.0 之间，已经完全够用」（07:44）；「减脂碳水小一点时，蛋白质就可以提高一点」（08:32）；上限以身体无压力（不胀气）为准。
  • 碳水：「从 2.5 到 3.5 克每公斤之间开始，体质偏容易胖从 2.5 开始，偏容易瘦从 3.5 开始」（09:36）。
  • 缺口：「一天可能也就两百到三百之间这个卡路里」的小缺口（03:40），保证训练强度不掉。
  • 波形调整：3.5 → 很饿则提到 4、5 → 一周后胃口下降再调回 3.5 或 3（10:54 起）。
  • 配套：每周 3–4 次有氧、每次 30–40 分钟（17:25）；早睡觉；保持微微饥饿感；记录体重 + 拍照对比。
  • 参考热量仅供对照（Mifflin-St Jeor / Katch-McArdle × 活动系数，非视频内容）；模式内的 g/kg 取值是按视频区间对目标速度做的插值。
